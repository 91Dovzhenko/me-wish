# 003-e — Отчёт Claude Code: корзина, профиль и общие состояния

**Дата:** 2026-11-24  **ТЗ:** `docs/tasks/003-e-trash-profile.md`  **Коммит:** «003-e: корзина с автоочисткой, профиль (имя, аватар, список по умолчанию), плашка «Нет интернета», ошибки сохранения, подсказка установки, значок ME:WISH»

## Сделано

### 1. Корзина
1. **Где открывается:** телефон — профиль → строка «Корзина» с числом; компьютер — меню профиля внизу бокового меню → «Корзина» с числом. Адрес — `/trash`.
2. **Список** по `Mobile-Trash` / `Desktop-Trash`:
   - фото, название, «Из «…» · удалится через N дн.» — и для удалённых списков тоже;
   - новые удалённые сверху;
   - подпись «Удалённые желания хранятся 30 дней…»;
   - пустая корзина — `Mobile-Trash-Empty` / `Desktop-Trash-Empty`.
   Удалённое из карточки желание появляется в корзине сразу.
3. **«Восстановить»:**
   - список жив — желание возвращается в него, тост «Восстановлено в «…»»;
   - список удалён — окно «Восстановить в список» с выбором (`Mobile-Trash-Restore`), предвыбран список по умолчанию, тост с выбранным списком.
4. **«Очистить корзину»** — подтверждение «Удалить навсегда N желаний?» (`Mobile-Trash-Clear`). Желания удаляются безвозвратно, их фото удаляются из Storage сразу.
5. **Автоочистка через 30 дней** — по расписанию, раз в сутки. Подробно — в разделе «Изменения в базе данных».

### 2. Профиль
6. **Страница профиля:** телефон — по нажатию на аватар (`Mobile-Profile`), компьютер — отдельная страница из меню (`Desktop-Profile`). Блоки по макетам; строка «Версия от … · синхронизация» осталась внизу (D-107).
7. **Имя:** нажатие → поле → «Сохранить» / «Отмена».
   - Пустое сохранить нельзя: «Напишите имя».
   - Имя сразу меняется в шапке (инициалы), в боковом меню и в профиле.
8. **Аватар:**
   - телефон — шторка «Загрузить фото» → выбор → обрезка с круглой рамкой (`Mobile-Avatar-Crop`);
   - компьютер — нажатие на фото сразу открывает выбор файла, затем окно обрезки (`Desktop-Avatar-Crop`);
   - фото сжимается до 400×400 и хранится в отдельном закрытом бакете;
   - ошибки — строкой под фото, как на `Mobile-Profile-AvatarError` («Не получилось загрузить фото: файл больше 20 МБ. Выберите другое.», не картинка, HEIC, нет связи).
   Новый аватар сразу виден в шапке, в боковом меню и в профиле.
9. **Способы входа:** «Google — Вход выполнен через него», без кнопок. Строка Telegram появится сама, когда у пользователя будет такой способ входа (003-f).
10. **Список по умолчанию:** телефон — шторка (`Mobile-Profile-DefaultList`), компьютер — выпадающий список (`Desktop-Profile-DefaultList`); текущий отмечен, сохраняется сразу. Форма «+» на главной открывается с этим списком — проверено.
11. **«Выйти»** — как было: на телефоне в профиле, на компьютере в меню.

### 3. Общие состояния
12. **«Нет интернета — изменения не сохранятся»** (`Mobile-Offline`) появляется и исчезает сама по состоянию сети.
    - Телефон — плашка сверху поверх экрана (и поверх открытой шторки).
    - Компьютер — над контентом.
13. **Ошибки сохранения:** прошёл по всем действиям. Где сохраняется что-то, при ошибке теперь тост «Не получилось сохранить — проверьте интернет»:
    - добавление и редактирование желания;
    - приоритет, статус, перемещение;
    - «Отменить» после удаления;
    - создание и настройки списка;
    - имя и список по умолчанию;
    - восстановление из корзины.

    Для удаления желания, удаления списка и очистки корзины — «Не получилось удалить — проверьте интернет».

    Форма при ошибке остаётся открытой, введённое не пропадает. В добавлении раньше была только строка над кнопкой — теперь ещё и тост.
14. **Подсказка «Добавьте ME:WISH на экран «Домой»»** (`Mobile-InstallHint`):
    - показывается один раз после первого входа, только в Safari на iPhone и iPad и только если приложение открыто не с экрана «Домой»;
    - в профиле на телефоне — строка «Как установить на iPhone» (её нет на макете, поэтому добавил неприметную, как сказано в ТЗ); в установленном приложении строки нет.

### 4. Значок приложения
15. Новые иконки: чёрный квадрат с лаймовым сердцем, как логотип в приложении.
    - `apple-touch-icon` (180), 192, 512 и маскируемая 512 для Android.
    - Для Dock на Mac — скруглённый квадрат с полями по сетке значков macOS.
    - Название на экране «Домой» и в Dock — «ME:WISH».
    - Иконки рисует скрипт `scripts/make-icons.swift`.

## Не сделано или сделано иначе, чем в ТЗ
- **«Удалить фото» у аватара не сделал:** на макете в шторке «Фото профиля» только «Загрузить фото» и «Отмена», а ТЗ просит эту кнопку, только «если это есть на макете». Плохое фото можно заменить другим.
- **На компьютере в профиле нет блоков «Корзина» и «Выйти»** — так на `Desktop-Profile`. Они в меню профиля внизу бокового меню (D-053, D-091).
- **Строка «Как установить на iPhone»** показывается на телефоне во всех браузерах, кроме установленного приложения. Сама подсказка (один раз) — только в Safari на iPhone/iPad.
- **Ограничение имени — 60 символов** (в документах длины нет; мелкое техническое решение).

## Изменения в базе данных
Миграция `supabase/migrations/20261127100000_trash_profile.sql` применена к облачному проекту и записана в историю. Таблицы не менялись.

- **Корзина:**
  - `trash_items()` — экран корзины, по участию в списке, с названием удалённого списка;
  - `restore_list_item_to(item, list)` — восстановить в выбранный список (security invoker, действуют политики);
  - `empty_trash(ids)` — удалить навсегда только показанные желания и только в списках, где пользователь редактор; возвращает пути фото.
- **Автоочистка:**
  - `purge_trash()` — по `pg_cron` в 03:00 UTC: появления старше 30 дней в корзине → желания без появлений → удалённые списки без появлений.
  - **Файлы Storage:** в 03:15 UTC `pg_cron` через `pg_net` вызывает Edge Function `storage-cleanup`. Она удаляет файлы старше суток, на которые ничего не ссылается: фото удалённых навсегда желаний, брошенные при добавлении фото (из 003-c), старые аватары. Список файлов отдаёт `storage_orphans()` — вызвать её может только сервер.
- **Аватары:**
  - бакет `avatars` (закрытый, до 1 МБ, WEBP/JPEG), путь `<user_id>/<uuid>.webp|jpg`;
  - **кто видит:** сам пользователь и участники общих с ним списков (на будущее, этап 2), и только текущий аватар профиля;
  - загружать, менять и удалять можно только в своей папке;
  - триггер `profiles_check_fields`: в профиль нельзя вписать аватар из чужой папки; имя не может быть пустым или длиннее 60 символов.
- **Edge Function и секреты:**
  - новая функция `storage-cleanup` выложена (с вашего согласия);
  - секрет `CLEANUP_SECRET` — в секретах Supabase, адрес проекта и тот же секрет — в Vault (для pg_cron);
  - в репозиторий секреты не попали.
- **Проверка RLS:** `supabase/tests/rls_003e_trash_profile.sql` — **30/30**, два пользователя. Проверено:
  - чужая корзина не видна;
  - чужое желание нельзя восстановить ни на место, ни в свой список;
  - чужую корзину нельзя очистить, и пути фото не возвращаются;
  - зритель общего списка не может очищать;
  - восстановить нельзя в удалённый и в чужой список;
  - чужой аватар не виден без общего списка и виден с ним;
  - аватар нельзя загрузить в чужую папку;
  - пустое и длинное имя не сохраняется;
  - служебные функции не вызываются пользователем;
  - аноним не может вызывать функции корзины.

  Старые тесты проходят: `rls_stage1` 27/27, `rls_003b_lists` 25/25, `rls_003c_wishes` 28/28, `rls_003d_wish_card` 30/30.
- **Проверка автоочистки:**
  - `supabase/tests/purge_003e.sql` — **5/5**. На тестовых данных сдвинута дата удаления (31, 29, 35, 40 и 5 дней): старше 30 дней удалены вместе с желаниями и пустым удалённым списком, моложе — на месте. Оба задания есть в расписании. Транзакция откатывается.
  - Функция уборки: без секрета отвечает 403. Команду ночного задания выполнил вручную: ответ `200`, удалены тестовые записи старше суток (по одной в обоих бакетах), свежая осталась.

## Как проверить
1. Удалите пару желаний и один список. Профиль → «Корзина» (на Mac — меню внизу бокового меню → «Корзина»): там эти желания с «Из «…»» и «удалится через 30 дн.».
2. «Восстановить» у желания из живого списка — оно вернулось в список. У желания из удалённого списка — появится выбор списка; выберите и восстановите.
3. «Очистить корзину» → «Удалить» — корзина пуста.
4. Профиль: нажмите на имя, введите «Виталий», «Сохранить» — имя поменялось в шапке (и в боковом меню на Mac). Нажмите на фото → «Загрузить фото» → обрежьте по кругу → «Готово».
5. Профиль → «Список по умолчанию» → выберите другой. На главной «+» → в поле «Список» стоит выбранный, желание попадает туда.
6. Включите авиарежим — сверху «Нет интернета…». Попробуйте добавить желание — тост об ошибке, форма с введённым на месте. Выключите авиарежим — плашка исчезла, «Добавить» сработает.
7. Удалите ME:WISH с экрана «Домой» и добавьте заново через Safari — значок чёрный с лаймовым сердцем, подпись «ME:WISH». Если подсказка ещё не показывалась, при первом открытии в Safari она появится сама; в профиле — строка «Как установить на iPhone».

## Технические решения
- **Корзина в общем снимке данных:** она грузится вместе с профилем, списками и желаниями. Поэтому число в профиле и в меню, экран корзины и сетка не расходятся, а Realtime и страховочное перечитывание (003-d) обновляют и её.
- **Удаление файлов:** «Очистить корзину» удаляет фото сразу из браузера. Автоочистка удаляет строки в базе, а файлы — ночная уборка через Edge Function: из SQL Storage удалять нельзя. Уборка не трогает файлы моложе суток, чтобы не задеть фото, которое как раз загружают в форму.
- **Аватар** при каждой загрузке получает новое имя файла: старый удаляется после сохранения профиля, а браузеры не показывают старую картинку из кэша.
- `src/lib/photos.ts` работает с двумя бакетами.
- Новые общие компоненты: `Sheet` (простая шторка), `ProfileAvatar`, `OfflineBanner`. У `Dialog` появилось поле внутри (выбор списка).
- Подробно — `docs/tech/trash-profile.md`.
- **Проверка в браузере** — на локальной заглушке Supabase (телефон 375/390 px и компьютер 1440 px):
  - профиль: имя, пустое имя, список по умолчанию → форма с главной;
  - аватар: обрезка, 400×400, ошибки «не картинка» и «нет связи»;
  - корзина: восстановление на место и в выбранный список, очистка с удалением фото, пустое состояние, меню профиля на компьютере;
  - плашка «Нет интернета» — появляется и исчезает;
  - тост и сохранность формы при ошибке;
  - подсказка: один раз, распознавание Safari на iPhone/iPad.

  Горизонтальной прокрутки на 390 px нет. В консоли только ошибки WebSocket заглушки (у неё нет Realtime).
- Сборка, линтер, prettier — чистые.
- **Новых зависимостей нет.** Edge Function использует `npm:@supabase/supabase-js@2` в среде Supabase, в зависимости приложения она не входит.

## Проблемы, риски, вопросы к продукту
- **Не проверено на настоящих устройствах:**
  - значок на экране «Домой» iPhone и в Dock Mac;
  - подсказка в настоящем Safari на iPhone;
  - загрузка аватара с iPhone.
- **Первая ночная автоочистка** пройдёт в 03:00–03:15 UTC (06:00–06:15 по Москве). Проверить: `select * from cron.job_run_details order by start_time desc limit 5;`.
- **Вопрос к продукту:** нужна ли кнопка «Удалить фото» у аватара (вернуть фото из Google / инициалы)? На макете её нет.
- **Вопрос к продукту:** строку «Как установить на iPhone» добавил сам (на макете её нет, но подсказка обещает «всегда есть в профиле»). Устраивает ли место — в блоке настроек под «Корзиной»?
