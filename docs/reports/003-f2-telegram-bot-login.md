# 003-f2 — Отчёт Claude Code: вход через Telegram-бота

**Дата:** 2026-11-24  **ТЗ:** `docs/tasks/003-f2-telegram-bot-login.md`  **Коммит:** «003-f2: вход через Telegram-бота по одноразовому коду — вебхук, ожидание подтверждения, аватар из Telegram»

## Сделано
1. **Вход через бота по одноразовому коду** (D-111) вместо страницы Telegram. Код входа через `oauth.telegram.org` удалён.
2. **Нажатие «Войти через Telegram»** сразу открывает Telegram с ботом ME:WISH.
   - На iPhone — само приложение Telegram, ME:WISH остаётся на месте (и в Safari, и в установленном приложении).
   - На компьютере — t.me в новой вкладке: оттуда Telegram Desktop или веб-версия.
3. **Экран ожидания** по образцу `Mobile-Login-Loading`: «Подтвердите вход в Telegram и вернитесь сюда», «Открыть Telegram ещё раз», «Отмена». Если iPhone выгрузит приложение, пока вы в Telegram, после возвращения ожидание продолжится.
4. **Бот:**
   - на «Start» по ссылке входа отвечает «Готово! Вернитесь в ME:WISH — вход выполнится сам.»;
   - на устаревшую или использованную ссылку — «Ссылка для входа устарела. Нажмите «Войти через Telegram» в ME:WISH ещё раз.»;
   - на любые другие сообщения — «Это бот для входа в ME:WISH. Добавление желаний через бота появится позже.»;
   - кнопки-ссылки на сайт нет.
5. **Приложение ждёт подтверждения:** опрос раз в 1,5 секунды и сразу при возвращении в приложение. После подтверждения вход выполняется сам («Входим…» → главная). Повторный вход тем же Telegram открывает тот же аккаунт.
6. **Ошибки:** через 10 минут без подтверждения — «Не получилось войти» и «Попробовать ещё раз»; «Отмена» возвращает экран входа.
7. **Аватар из Telegram — сделан.**
   - При первом входе сервер берёт фото профиля через Bot API и сохраняет в бакет аватаров как своё фото (размер ближайший к 400 px, JPEG).
   - Бесплатно, без новых зависимостей.
   - Если фото нет или оно скрыто настройками приватности Telegram — инициалы.

## Схема входа и безопасность
1. Экран входа заранее просит сервер создать запрос: **код** (12 знаков) и **секрет устройства** (длинный, случайный).
   - Секрет остаётся только в браузере, в базе — только его хэш.
   - Запрос живёт 10 минут.
   - Заранее — потому что iPhone открывает Telegram только прямо по нажатию.
2. Нажатие открывает бота со ссылкой `start=login_<код>`.
3. «Start» в боте → Telegram присылает сообщение на вебхук. Вебхук принимает его только с секретным заголовком `X-Telegram-Bot-Api-Secret-Token` и подтверждает живой запрос **один раз**, привязывая к нему `telegram_id` и имя.
4. Приложение опрашивает сервер **кодом + секретом**. Без секрета код ничего не даёт: тот, кто увидит код, войти не сможет. Подтверждённый запрос обменивается на сессию тоже один раз.
5. Сервер находит или создаёт пользователя по `telegram_id` (как в 003-f) и выдаёт одноразовый токен. Браузер меняет его на обычную сессию Supabase.
6. Таблица запросов клиентам недоступна совсем (RLS без политик, права убраны). Старые запросы удаляет ночная уборка.

Подробно — `docs/tech/telegram-login.md`.

## Не сделано или сделано иначе, чем в ТЗ
- **На iPhone бот открывается ссылкой `tg://resolve?domain=me_wish_bot&start=login_…`, а не `https://t.me/…`.** Это та же ссылка на бота, только сразу в приложение Telegram. Из установленного приложения ссылка `https://t.me` может открыться во встроенном окне Safari со страницей «Open in Telegram» — лишний шаг, после которого это окно надо закрывать. На компьютере используется `https://t.me/…`, как в ТЗ.
- **Телефон с Telegram только в браузере** (без приложения) на iPhone не поддержан: ссылка `tg://` в этом случае ничего не откроет. Для Олеси с установленным Telegram это не важно.

## Как перерегистрировать вебхук
Нужно, если сменится токен бота, адрес проекта Supabase или секрет. В терминале в папке проекта:

```bash
S=$(openssl rand -hex 32)
supabase secrets set TELEGRAM_WEBHOOK_SECRET=$S
```

Подождите ~10 секунд, затем:

```bash
curl -s -X POST -H "x-telegram-setup: $S" https://ldpxoyqpxesypgxjakxf.supabase.co/functions/v1/telegram-webhook
```

В ответе должно быть `"Webhook was set"`. Функция сама вызовет `setWebhook` с токеном из секретов Supabase. Или попросите меня.

## Что сделать вам
1. **GitHub:** переменную `VITE_TELEGRAM_BOT_ID` можно удалить (Settings → Secrets and variables → Actions → Variables → `VITE_TELEGRAM_BOT_ID` → удалить). Она больше не нужна; если оставить, ничего не сломается. `VITE_TELEGRAM_BOT_NAME` = `me_wish_bot` оставьте.
2. Запушьте коммит в GitHub Desktop.
3. В Supabase ничего делать не нужно: функции, секрет вебхука и вебхук уже на месте.

## Как проверить
1. На iPhone Олеси полностью закройте ME:WISH и откройте с экрана «Домой». Подождите, пока обновится до новой версии: в профиле внизу «Версия от 24 ноября …». Если версия старая — закройте и откройте ещё раз.
2. «Войти через Telegram» → откроется Telegram с ботом ME:WISH → «Start» (или «Запустить»).
3. Бот ответит «Готово! Вернитесь в ME:WISH…». Переключитесь в ME:WISH — через пару секунд откроется главная.
4. Профиль → «Способы входа»: Telegram; фото из Telegram, если оно открыто в настройках приватности. Выйдите и войдите снова — тот же аккаунт.
5. То же в Safari на iPhone и в браузере на Mac (Telegram Desktop или веб-версия).
6. На своём устройстве вход через Google работает как раньше.
