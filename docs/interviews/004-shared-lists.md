# 004 — Интервью: совместные списки (этап 2)

**Дата:** 2026-11-24  **Участники:** владелец, продуктовый чат
**Связано:** интервью 000 (совместные списки и голосование), D-011…D-013, D-085, SPEC §2.3, §6

## Что было известно до интервью
Две роли — редактор и зритель, права редакторов равные (D-011); голосование редакторов, единогласно, включается в настройках (D-012, D-013); приглашение ссылкой с ролью; разделы «Совместные» и «Со мной поделились».

## Блок 1
1. **Приглашение** — «•••» → «Участники» → «Пригласить»: выбрать роль → ссылка → отправить в мессенджере. Приглашённый открывает, входит при необходимости, видит «Виталий приглашает вас в «Для дома» — Принять». Ссылка многоразовая, 7 дней, можно отозвать. Без приглашений по почте и контактам. — **согласен**
2. **Любой список становится совместным**, когда появился второй участник; отдельного типа нет. — **согласен**
3. **Главная:** разделы «Мои списки» (только я), «Совместные» (несколько редакторов), «Со мной поделились» (я зритель; Q-03 — это название); пустые разделы скрыты; на обложке совместного — аватары участников; в боковом меню — те же разделы. — **согласен**
4. **Кто добавил:** маленький аватар добавившего на карточке совместного списка, в открытой карточке «Добавила Олеся · 12 ноября»; уведомлений пока нет (бэклог, с ботом). — **согласен**
5. **Голосование** — **отложено в бэклог** (решение владельца). Этап 2 — совместные списки без голосования.
6. **Выход и удаление:** любой участник может выйти; редактор может убрать участника; «Удалить список» в совместном — для всех, с предупреждением; ушёл последний редактор — список удаляется. — **согласен**

## Блок 2
1. **Роль «зритель» — сейчас:** видит список, ничего не меняет; бронирование — на этапе 4. — **согласен**
2. **Статус и приоритет** в совместном списке меняет любой редактор, они общие для списка. — **согласен**
3. **Корзина:** удалённое любым редактором видно в корзине у всех редакторов списка, восстановить может любой. — **согласен**
4. **Сводка на главной** считает списки, где я редактор (мои + совместные); «Со мной поделились» не считаются. — **согласен**
5. **Участники:** видны все (аватар, имя, роль); любой редактор меняет роль и убирает участника; совместный список может быть «списком по умолчанию». — **согласен**
