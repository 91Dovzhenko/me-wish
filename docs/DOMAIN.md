# me:wish — предметная модель

## 1. Сущности

| Сущность | Смысл |
|---|---|
| **User** | Зарегистрированный пользователь (Telegram и/или Google) |
| **TelegramLink** | Привязка чата Telegram к пользователю или гостю |
| **List** | Список желаний (доска) с настройками |
| **ListMember** | Участие пользователя в списке с ролью |
| **Wish** | Само желание: общие данные (название, картинка, цена, ссылка, статус) |
| **ListItem** | Появление желания в конкретном списке: приоритет, позиция |
| **Vote** | Голос редактора за ListItem |
| **Booking** | Бронь желания дарителем |
| **Guest** | Даритель без аккаунта, опознаётся по токену |
| **Invite** | Приглашение в список с ролью |

Связь Wish ↔ List — **многие ко многим через ListItem**. До этапа 5 у каждого Wish ровно один ListItem, но схема с первого дня такая, чтобы потом не переделывать.

## 2. Статусы желания (Wish.status — общий для всех списков)

```
active ──бронь──▶ booked ──отмечено владельцем──▶ gifted
  │                 │
  │                 └─отмена брони──▶ active
  │                 └─«Куплено» (с предупреждением)──▶ purchased
  └─«Куплено»──▶ purchased
```

Названия в интерфейсе (D-058): `active` — «Хочу», `purchased` — «Куплено», `gifted` — «Подарили», `booked` — «Забронировано».

- `active` — активно, можно бронировать.
- `booked` — есть действующая бронь (производное от Booking; можно хранить вычисляемо).
- `purchased` — куплено самим владельцем. Завершено.
- `gifted` — подарено. Завершено.
- Завершённые (`purchased`, `gifted`) показываются в группе «Исполнено» и скрываются переключателем.
- Владелец может вернуть завершённую карточку в `active`.

**Удаление — не статус.** `ListItem.deleted_at` (корзина, 30 дней). Если удалены все ListItem желания — желание тоже считается в корзине.

## 3. Поля

### List
`id, title, icon, description, event_date?, cover_wish_id?, visibility (private|link), public_slug?, booking_enabled, anonymity_mode (choice|anonymous_only|open_only), voting_enabled, archived_at?, created_by, created_at`

### ListMember
`list_id, user_id, role (editor|viewer), added_at`

### Wish (общие поля)
`id, title, description?, image_path?, source_url?, price?, currency (RUB|USD|EUR)?, status, completed_at?, created_by, created_at, updated_at`

`description` — свободный текст: размер, цвет, модель, пожелания (D-063). `source_url` — ссылка без рекламных меток (D-061). Полей разбора (`canonical_url`, `source_domain`, `parse_status`) нет — автозаполнения нет (D-059).

`completed_at` — когда карточка перешла в `purchased` или `gifted` (сбрасывается при возврате в `active`). Нужно для «исполнено за год» на дашборде (D-050).

### ListItem (поля конкретного списка)
`id, list_id, wish_id, priority (1–5)?, position, added_by, added_at, deleted_at?`

### Vote
`list_item_id, user_id, value (approve|reject), updated_at` — один голос на пару.
Группа ListItem вычисляется: все редакторы `approve` → «Одобрено всеми»; все `reject` → «Отклонено всеми»; есть оба → «Нужно решить»; иначе → «Ждёт голосов».

### Booking
`id, wish_id, list_id (где сделана бронь), booker_user_id? | guest_id?, display_name?, is_anonymous, status (active|cancelled|fulfilled), created_at, cancelled_at?`
Одна активная бронь на Wish.

### Guest
`id, token_hash, email?, created_at, last_seen_at`

### TelegramLink
`chat_id, user_id? | guest_id?, username?, linked_at`

### User (профиль)
`id, display_name, avatar_url?, default_list_id?, telegram_id?, google_sub?`

## 4. Роли и права

| Действие | Редактор | Зритель | Гость по ссылке |
|---|---|---|---|
| Видеть список и карточки | ✅ | ✅ | ✅ (если видимость «по ссылке») |
| Добавлять / изменять / удалять карточки | ✅ | — | — |
| Менять общие поля связанной карточки | ✅ (если редактор хотя бы одного её списка) | — | — |
| Голосовать и видеть голоса | ✅ | — | — |
| Бронировать | ✅* | ✅* | ✅* |
| Приглашать участников, менять роли | ✅ | — | — |
| Менять настройки, архивировать, удалять список | ✅ | — | — |

\* если в списке включено бронирование.

У всех редакторов одинаковые права; создатель списка — просто первый редактор. Если удаляется последний редактор — список удаляется.

## 5. Видимость данных брони

- `display_name` открытой брони виден всем, кто видит список.
- Для анонимной брони наружу отдаётся только «Анонимно».
- Email, `chat_id`, `guest_id`, `booker_user_id` анонимной брони **никогда не отдаются** никому, кроме самого дарителя. Для открытой брони контакты тоже не отдаются (только имя).
- Гость видит, какие брони «его», только по своему токену.

## 6. Инварианты

- У Wish не больше одной активной брони.
- Нельзя забронировать Wish в статусе `purchased`/`gifted`.
- Нельзя забронировать в списке с `booking_enabled = false`.
- Голоса доступны только при `voting_enabled = true`; при выключении голоса сохраняются, но не показываются.
- Сумма списка = сумма `price` по ListItem без `deleted_at`, статус не завершён, `currency = RUB`.
