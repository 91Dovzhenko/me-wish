## Правки после итерации 2 (D-066…D-077) — приоритет над текстом ниже
- Фото везде квадратное, заполняет квадрат; обрезка — только квадрат + приближение/перетаскивание (телефон — пальцы, компьютер — ползунок/колесо/трекпад).

Статус — выпадающий список «В желаниях / Куплено / Подарили», меняется в любую сторону. «•••» — «Редактировать», «Переместить», «Удалить».

- Список: иконка (~30) + цвет при создании; иконка в боковом меню и на пустой обложке.
- Компьютер: логотип ME:WISH; «+ Новый список» в боковом меню, плитки на главной нет; корзина — в меню профиля; экран списка на компьютере.
- Раздел холста «Спецификация» вместо «Компоненты».

## Полный флоу этапа 1 (D-078…D-084) — экраны и состояния, которые должны быть на холсте
- **Вход:** компьютер; «Входим…» после Telegram; ошибка входа; подсказка «Установить на экран «Домой»» для iPhone (в профиле и один раз после первого входа).
- **Главная:** загрузка (скелетоны); много списков (8+, на компьютере боковое меню прокручивается).
- **Список:** пустой изнутри; группа «Исполнено» внизу; всё исполнено; без описания и даты; загрузка.
- **Добавление:** подсказка о формате фото (D-084); фото загружается; ошибка фото (не тот файл / больше 20 МБ / маленькое — предупреждение); на компьютере — перетаскивание над формой; пустое название при нажатии «Добавить»; телефон с открытой клавиатурой; «Не сохранять желание?»; тост «Добавлено в «…» · Открыть».
- **Карточка:** без фото / без цены / без ссылки (нет «Перейти в магазин») / без описания; редактирование (та же форма, «Редактировать» / «Сохранить», «Не сохранять изменения?»); «Переместить» — выбор списка; удаление — тост «Удалено · Отменить» (D-080).
- **Список — настройки:** редактирование; удаление с подтверждением «Удалить список и N желаний?»; последний список — «Удалить» недоступно с пояснением (D-082). Видимости и «Поделиться» на этапе 1 нет (D-079).
- **Профиль:** изменение имени; способы входа (подключение второго — этап 3, бот) (D-083).
- **Корзина:** восстановление в удалённый список — окно выбора списка с предвыбранным по умолчанию; «Очистить корзину» с подтверждением.
- **Общее:** тосты (сохранено, удалено + «Отменить», ошибка сети); нет интернета; «Страница не найдена»; диалог подтверждения.

## Задача
Человек входит, видит свои списки и сводку, добавляет желание одной короткой формой (фото со скриншота, название, цена, ссылка), открывает карточку, переходит в магазин, отмечает «Куплено» / «Подарили», управляет списками и корзиной. Всё удобно на iPhone (390px) и на компьютере.

## Общий стиль (DESIGN.md)
- Семейство ME:LVL концептуально (D-046): светлый почти белый фон, белые/светло-серые блоки с большим скруглением, почти чёрный текст, жирные заголовки, минимализм Things/Pinterest. Шрифты — мягче, чем в ME:LVL.
- Палитра (D-052): лайм — главные действия (кнопка «+», «Перейти в магазин», активный пункт меню); лаванда — второй акцент и лёгкие градиенты местами (блок дашборда, пустые состояния). Без градиентов «везде».
- Только светлая тема (D-055), цвета — переменными.
- Карточки товаров в духе Яндекс Маркета: фото сверху, цена крупно, название в 2 строки.
- Приоритет (D-056): 5 уровней — «Можно и без», «Было бы неплохо», «Хочу», «Очень хочу», «Мечта»; значок из сердечек (показать вариант с точками/огоньками для сравнения); у 4–5 — акцентная метка.
- Статусы (D-058): «Хочу», «Куплено», «Подарили». Исполненные — приглушены, с бейджем на фото.
- Навигация (D-047): компьютер — левая боковая панель + контент в большой белой скруглённой панели; телефон — шапка + круглая плавающая лаймовая «+» внизу справа, без нижних вкладок.

## Экраны

### 1. Вход
- **Данные:** логотип me:wish, одна строка о продукте («Списки желаний из одной ссылки»), иллюстрация-коллаж карточек.
- **Действия:** «Войти через Telegram» (основная), «Войти через Google».
- **Состояния:** обычное; ошибка входа (короткое сообщение + «Попробовать ещё раз»).
- **Мобильная / десктоп:** телефон — по центру, кнопки внизу; компьютер — карточка входа по центру на фоне с лёгким лавандовым градиентом.

### 2. Главный экран
- **Данные:** шапка (логотип, аватар → меню профиля); блок дашборда (D-050): «Активные» — количество и сумма ₽, «Исполнено в 2026» — количество и сумма ₽; раздел «Мои списки» — обложки-коллажи (D-051): коллаж 3–4 фото, название, количество карточек, сумма ₽, дата события (если есть), дата последнего добавления; плитка «+ Новый список».
- **Действия:** открыть список, создать список, «+» → окно «Добавить» (с выбором списка), аватар → меню.
- **Состояния:** первый вход — один пустой список «Мои желания» (D-048), дашборд с нулями и подсказка «Добавьте первое желание — хватит названия, остальное по желанию»; обычное (3–6 списков); загрузка (скелетоны); список без карточек — обложка-заглушка.
- **Мобильная:** шапка → дашборд → обложки в 2 колонки → «+» плавает. **Корзины на главной нет** (D-053).
- **Десктоп:** боковая панель: логотип, «Главная», раздел «Мои списки» (каждый список с числом карточек), «+ Новый список»; внизу неприметно — «Корзина», профиль. Контент: дашборд + обложки в 3–4 колонки.

### 3. Список
- **Данные:** название, описание, дата события; сводка по списку (активные: кол-во + сумма ₽; исполнено: кол-во + сумма ₽; сортировка (по умолчанию «По приоритету», D-057; также цена ↑↓, дата, статус); переключатель «Показывать исполненные»; сетка карточек; группа «Исполнено» внизу.
- **Карточка в сетке:** фото, цена крупно, название в 2 строки, приоритет (сердечки, метка у 4–5), бейдж статуса на фото для исполненных. Магазин отдельно не показываем (D-061).
- **Действия:** открыть карточку, «+» → «Добавить» сразу в этот список, сменить сортировку, «•••» → «Настройки списка», «Удалить список».
- **Состояния карточек:** обычная, без фото (аккуратная заглушка), без цены, исполненная (приглушена). Состояний «загружается» и «частичная» нет (D-059).
- **Состояния списка:** пустой — подсказка + кнопка «Добавить первое желание»; все исполнены; длинный список.
- **Мобильная:** 2 колонки (видно 3–4 карточки целиком). **Десктоп:** 4–6 колонок, список подсвечен в боковой панели.

### 4. Открытая карточка (D-067…D-071; ниже — исходный текст, см. правки выше)
- **Данные:** большое фото, название, цена ₽, приоритет — 5 сердечек + подпись уровня, статус, описание (размер, цвет, модель), список, дата добавления.
- **Действия:** **«Перейти в магазин»** (главная, лайм; на телефоне закреплена внизу); кнопки **«Куплено»** и **«Подарили»** на виду; у исполненной — «Вернуть в желания»; смена приоритета в одно нажатие; «•••» → «Изменить», «Удалить» (в корзину).
- **Состояния:** обычная; без фото / без цены (ненавязчивое «Добавить фото» / «Указать цену»); без ссылки (нет кнопки магазина); исполненная; режим редактирования (та же форма, что при добавлении).
- **Мобильная:** отдельный экран со стрелкой «назад». **Десктоп:** страница в контентной панели: фото слева, данные и действия справа.
- Показать на дизайне и вариант «окно поверх списка» для сравнения (D-049 — гипотеза).

### 5. Окно «Добавить» (SPEC §4.1, D-061–D-063)
- **Одна форма, без переключателя режимов:** блок фото сверху (пустой — «Добавить фото»: галерея/скриншот; на компьютере — ещё вставка Cmd+V и перетаскивание), **название** (обязательно), цена ₽, ссылка, описание (размер, цвет, модель). «Подробнее» — приоритет, выбор списка (если открыто с главной). Кнопка «Добавить».
- **Обрезка фото:** сразу после выбора — экран обрезки (рамка, «Готово»), чтобы скриншот с маркетплейса превратить в аккуратное фото товара.
- **Состояния:** пустое; фото выбрано; обрезка; загрузка фото; ошибка загрузки фото; не заполнено название (подсказка); после добавления — уведомление «Добавлено в «Мои желания»» с «Открыть».
- **Мобильная:** шторка снизу (на всю высоту, клавиатура не перекрывает кнопку). **Десктоп:** окно по центру.

### 6. Создание и настройки списка
- **Данные:** название (обязательно), описание, дата события, иконка и цвет (D-075), обложка (авто-коллаж / выбрать карточку). Видимости нет (D-079).
- **Действия:** «Создать» / «Сохранить», «Удалить список» (подтверждение).
- **Мобильная:** шторка или отдельный экран. **Десктоп:** окно по центру.

### 7. Меню профиля и профиль
- **Данные:** аватар, имя, способы входа, список по умолчанию.
- **Действия:** сменить список по умолчанию, «Корзина», «Выйти».
- **Мобильная:** по нажатию на аватар — меню/экран. **Десктоп:** из низа боковой панели.

### 8. Корзина
- **Данные:** удалённые карточки (фото, название, из какого списка, «удалится через N дн.»).
- **Действия:** «Восстановить», «Очистить корзину» (подтверждение).
- **Состояния:** пустая («Корзина пуста»), с карточками.

## Сценарий по шагам (главный)
1. Вход через Telegram → главный экран с пустым списком «Мои желания» и подсказкой.
2. «+» → выбрать скриншот → обрезать → название, цена → вставить ссылку → «Добавить» → карточка в списке.
3. Открыть карточку → поставить «Мечта» → «Перейти в магазин».
4. Позже: «Подарили» → карточка уходит в «Исполнено», на дашборде растёт «Исполнено в 2026».

## Ограничения и принципы
- Сначала мобильная версия (390px), потом десктоп. Кнопка «+» всегда под рукой.
- Мало действий: добавление — один экран, обязательно только название.
- Пустые состояния объясняют, что делать.
- Тексты интерфейса — по-русски, коротко.

## Не входит
- Совместные списки, голосование, разделы «Совместные» / «Со мной поделились» (этап 2).
- Публичная страница, бронирование (этап 4). Бейдж «Забронировано» — не рисуем.
- Архив, перенос карточек (этап 5). Тёмная тема, поиск и фильтры (бэклог).
- Настоящие логотип и иконка приложения — отдельной задачей позже (сейчас — рабочий вариант).
