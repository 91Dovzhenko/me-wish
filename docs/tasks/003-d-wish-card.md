## Что сделать

### 1. Открытая карточка
4. **Открытие:** нажатие на карточку в сетке открывает её.
   - На телефоне — шторка на всю высоту, на компьютере — окно по центру поверх списка (D-067).
   - У карточки свой адрес, например `/l/<list>/w/<item>`: можно открыть напрямую и обновить страницу — откроется список и поверх него карточка. Чужое или удалённое желание — «Страница не найдена».
   - Закрытие — крестик, касание по фону, Esc на компьютере.
5. **Содержимое и порядок** — по `Mobile-Card` / `Desktop-Card` (D-068, D-087):
   - квадратное фото;
   - название — целиком;
   - цена и приоритет в одной строке;
   - описание — 4 строки и «Ещё» → раскрывается полностью;
   - статус;
   - «Перейти в магазин» — на телефоне закреплена внизу.
6. **Приоритет без редактирования:** нажатие на строку приоритета открывает выбор из 5 уровней (`Mobile-Card-Priority`, `Desktop-Card-Priority`). Выбор сразу сохраняется, порядок в сетке обновляется.
7. **Статус** — выпадающий список «В желаниях» / «Куплено» / «Подарили» (`Mobile-Card-Status`, D-069, D-070).
   - Меняется в любую сторону, сразу сохраняется.
   - `completed_at` ставит и сбрасывает база (уже есть).
   - Исполненная карточка — по `Mobile-Card-Done`.
8. **«Перейти в магазин»** открывает сохранённую ссылку в новой вкладке / во внешнем браузере. Без ссылки кнопки нет (`Mobile-Card-NoLink`).
9. **Без фото и без цены** — «+ Добавить фото» и «+ Указать цену» (`Mobile-Card-NoPhoto`) открывают редактирование.
10. Под описанием — «В списке «…» · добавлено <дата>», если это есть на макете.

### 2. Меню «•••», редактирование, перемещение, удаление
11. **Меню «•••»** (`Mobile-Card-Menu`, `Desktop-Card-Menu`, D-071): «Редактировать», «Переместить», «Удалить» (красным).
12. **«Редактировать»** — та же форма, что при добавлении, с заполненными полями (`Mobile-Card-Edit`):
    - заголовок «Редактировать», кнопка «Сохранить»;
    - фото можно обрезать заново, заменить или удалить; старый файл в Storage удаляется после успешного сохранения;
    - закрытие с изменениями — «Не сохранять изменения?» (`Mobile-Card-Edit-Discard`).
13. **«Переместить»** (`Mobile-Card-Move`, `Desktop-Card-Move`):
    - список своих неудалённых списков с иконкой, названием и числом желаний, текущий отмечен;
    - выбор переносит желание: меняется `list_items.list_id`;
    - после переноса — тост «Перемещено в «…»», карточка закрывается;
    - счётчики обоих списков обновляются.
14. **«Удалить»** (D-080):
    - без подтверждения: карточка закрывается, желание уходит в корзину (`list_items.deleted_at`);
    - внизу тост «Удалено · Отменить» (6 секунд, `Mobile-List-Deleted`);
    - «Отменить» возвращает желание на место.

    Экран корзины — 003-e.

### 3. Сортировка и «Исполненные»
15. **Сортировка** (`Mobile-List-Sort`, `Desktop-List-Sort`, SPEC §3.4):
    - варианты: «По приоритету» (по умолчанию: сверху «Мечта», при равном — новые), «Сначала дешёвые», «Сначала дорогие», «По дате добавления» (новые сверху), «По статусу»;
    - «Без цены» в сортировке по цене — в конце;
    - выбор запоминается для каждого списка на этом устройстве.
16. **«Исполненные»** — переключатель-чип: показывать или скрывать исполненные. По умолчанию показываются.
    - Исполненные («Куплено», «Подарили») стоят отдельной группой «Исполнено · N» внизу (`Mobile-List-DoneGroup`): приглушённые, с меткой статуса на фото.
    - Если исполнено всё — по `Mobile-List-AllDone`.
17. **Сводка списка и главной** считает активные и исполненные с учётом смены статусов (главная — исполнено за текущий год).

## Критерии приёмки
- [ ] Синхронизация: изменения в обе стороны (iPhone ↔ Mac) появляются в открытом списке без выхода из него; сетка, сводка, счётчики и обложки всегда совпадают.
- [ ] Карточка открывается шторкой (телефон) или окном (компьютер), по прямой ссылке тоже; содержимое и состояния — по макетам.
- [ ] Приоритет и статус меняются прямо в карточке, порядок и сводка обновляются.
- [ ] Редактирование (включая фото), перемещение с тостом, удаление с «Отменить» работают.
- [ ] Сортировка (5 вариантов, запоминается), «Исполненные» и группа «Исполнено» — по макетам.
- [ ] RLS проверены на двух пользователях.
- [ ] 390 px без горизонтальной прокрутки, ошибок в консоли нет, сборка и линтер чистые.

## Как проверить (для владельца)
1. Откройте «Мои желания» на iPhone и на Mac одновременно. Добавьте желание на Mac — через пару секунд оно появится на iPhone, не выходя из списка, и «Активные» увеличится.
2. На iPhone нажмите на карточку «Кофе» — откроется шторка с фото, ценой и сердечками в одной строке, описанием, статусом и «Перейти в магазин».
3. Нажмите на сердечки → выберите «Очень хочу». Нажмите на статус → «Куплено». Закройте карточку: она в группе «Исполнено» внизу, «Активные» уменьшилось.
4. «•••» → «Редактировать» → поменяйте цену → «Сохранить».
5. «•••» → «Переместить» → другой список → тост «Перемещено».
6. «•••» → «Удалить» → внизу «Удалено · Отменить» → нажмите «Отменить» — карточка вернулась.
7. Сортировка → «Сначала дорогие». Выключите «Исполненные» — группа «Исполнено» скрылась.
8. На Mac то же самое: карточка открывается окном поверх списка.
