# 003-e — ТЗ для Claude Code: корзина, профиль и общие состояния

**Этап:** 1 (пятое из шести ТЗ, D-098)  **Связано:** SPEC §1.4, §5.7; DOMAIN §2 (удаление), §3 (User); DECISIONS D-053, D-080, D-082, D-083, D-084, D-091, D-096, D-099, D-100, D-101, D-107; бриф `docs/design-briefs/003-personal-wishlist.md`
**Дизайн:** выгрузка `docs/design/stage1/`. **Если ТЗ и макет расходятся — делай по макету (D-101).**
- корзина: `Mobile-Trash`, `Mobile-Trash-Empty`, `Mobile-Trash-Restore`, `Mobile-Trash-Clear`, `Desktop-Trash`, `Desktop-Trash-Empty`;
- профиль: `Mobile-Profile`, `Mobile-Profile-Name`, `Mobile-Profile-Avatar`, `Mobile-Profile-AvatarError`, `Mobile-Profile-DefaultList`, `Mobile-Avatar-Crop`, `Desktop-Profile`, `Desktop-Profile-Name`, `Desktop-Profile-DefaultList`, `Desktop-Avatar-Crop`, `Desktop-ProfileMenu`;
- общее: `Mobile-Offline`, `Mobile-InstallHint`, `Spec-Feedback`.

## Контекст
003-a…003-d готовы и проверены владельцем.
- Желания удаляются в корзину: `list_items.deleted_at`, при удалении списка — вместе с мягко удалённым списком.
- Экрана корзины нет. Как хранится удалённое и что нужно корзине — `docs/tech/lists.md`, `docs/tech/wish-card.md`.
- Профиль сейчас упрощённый: имя, аватар, «Выйти», строка версии (D-107).
- Значок приложения временный фиолетовый (D-100).

Это ТЗ закрывает этап 1, кроме входа через Telegram (003-f).

## Что сделать

### 1. Корзина
1. **Где открывается:**
   - телефон — профиль → строка «Корзина» с числом;
   - компьютер — меню профиля внизу бокового меню → «Корзина» (D-053).

   Своя страница с адресом, например `/trash`.
2. **Список** (`Mobile-Trash`, `Desktop-Trash`):
   - удалённые желания пользователя: фото, название, из какого списка («из «День рождения»» — и для удалённых списков тоже), «удалится через N дн.»;
   - сверху — новые удалённые;
   - пустая — `Mobile-Trash-Empty` / `Desktop-Trash-Empty`.
3. **«Восстановить»:**
   - если список желания жив — желание возвращается в него, тост «Восстановлено в «…»»;
   - если список удалён — окно «Восстановить в список» с выбором (`Mobile-Trash-Restore`), предвыбран список по умолчанию, можно поменять (D-082).
4. **«Очистить корзину»** — подтверждение «Удалить навсегда N желаний?» (`Mobile-Trash-Clear`). После подтверждения желания удаляются безвозвратно, вместе с их фото в Storage.
5. **Автоочистка через 30 дней** (SPEC §5.7):
   - раз в сутки по расписанию (`pg_cron` в Supabase, бесплатно) удаляются появления, пролежавшие в корзине больше 30 дней;
   - затем удаляются желания, у которых не осталось появлений, и их фото в Storage;
   - удаляются и мягко удалённые списки, у которых больше нет появлений.

   Как удалять файлы из Storage по расписанию (Edge Function по расписанию или другой способ), реши сам. Можно Edge Function — она бесплатна; секреты только в секретах Supabase. Подбери и осиротевшие фото из 003-c (`docs/tech/wishes.md`). Запиши устройство в `docs/tech/`.

### 2. Профиль
6. **Страница профиля:**
   - телефон — по нажатию на аватар (`Mobile-Profile`);
   - компьютер — отдельная страница из меню профиля (`Desktop-Profile`, D-091).

   Блоки по макету: аватар и имя; способы входа; список по умолчанию; корзина; «Выйти». Строку «Версия от … · синхронизация на связи» оставь внизу (D-107).
7. **Имя:** нажатие на имя → поле → «Сохранить» (`Mobile-Profile-Name`, `Desktop-Profile-Name`).
   - Пустое имя сохранить нельзя.
   - Имя обновляется везде: в шапке и в боковом меню.
8. **Аватар** (`Mobile-Profile-Avatar`, `Mobile-Avatar-Crop`, `Desktop-Avatar-Crop`):
   - нажатие на аватар → «Загрузить фото» → выбор → обрезка с круглой рамкой (компонент обрезки из 003-c);
   - сжатие примерно до 400×400 и загрузка в Storage — отдельный бакет или папка, видят сам пользователь и участники общих с ним списков (на будущее, этап 2);
   - ограничения фото — как у желаний (D-084);
   - ошибка загрузки — `Mobile-Profile-AvatarError`;
   - «Удалить фото» возвращает аватар из Google или инициалы, если это есть на макете.
9. **Способы входа** — только показываем, через что вход: «Google — вход выполнен», без кнопок «Подключить» (D-091). Когда появится Telegram (003-f), строка Telegram добавится сама.
10. **Список по умолчанию** — выбор из неудалённых списков (`Mobile-Profile-DefaultList`, `Desktop-Profile-DefaultList`), текущий отмечен. Новые желания с главной добавляются в него.
11. **«Выйти»** — как сейчас.

### 3. Общие состояния
12. **Нет интернета** — плашка сверху «Нет интернета — изменения не сохранятся» (`Mobile-Offline`), появляется и исчезает сама по состоянию сети. На компьютере — по аналогии, над контентом.
13. **Ошибки сохранения** — во всех местах, где что-то сохраняется: добавление, редактирование, статус, приоритет, перемещение, удаление, списки, профиль. Если запрос не прошёл — тост «Не получилось сохранить — проверьте интернет» (`Spec-Feedback`), введённые данные в форме не теряются. Пройди по всем действиям и проверь, что ни одно не падает молча.
14. **Подсказка «Добавьте ME:WISH на экран «Домой»»** (`Mobile-InstallHint`):
    - только для iPhone и iPad в Safari, когда приложение открыто не как установленное (не в режиме standalone);
    - показывается один раз после первого входа, кнопка «Понятно»;
    - всегда доступна в профиле — строкой, если она есть на макете; если нет, добавь неприметную строку «Как установить на iPhone».

### 4. Значок приложения (D-100)
15. Иконки PWA и `apple-touch-icon` — знак ME:WISH (чёрный скруглённый квадрат с лаймовым сердцем, как логотип в приложении) вместо временных фиолетовых. Нужны все размеры, включая маскируемую иконку для Android. Название на экране «Домой» — «ME:WISH».

## Что НЕ делать
- Вход через Telegram, подключение второго способа входа — 003-f / этап 3.
- Свайп шторок (D-106).
- Удаление аккаунта, политику конфиденциальности (бэклог, перед публичным запуском).
- Восстановление удалённого списка целиком.

## Изменения в базе данных
- Функция для экрана корзины: желание, дата удаления, название исходного списка, жив ли он; с RLS, по участию.
- Восстановление в живой или выбранный список; безвозвратное удаление («Очистить корзину»).
- Расписание автоочистки (`pg_cron`) и удаление файлов Storage.
- Хранилище аватаров с RLS; поле `profiles.avatar_path` уже есть.
- RLS-проверка на двух пользователях: чужую корзину нельзя увидеть, восстановить, очистить; чужой аватар — только при общем списке.

## Критерии приёмки
- [ ] Корзина открывается с телефона (профиль) и с компьютера (меню профиля); список, пустое состояние, «удалится через N дн.» — по макетам.
- [ ] Восстановление в живой список и в выбранный (если список удалён); «Очистить корзину» с подтверждением удаляет навсегда, вместе с фото.
- [ ] Автоочистка через 30 дней настроена; как проверял — в отчёте (например, на тестовых данных со сдвинутой датой).
- [ ] Профиль: имя меняется и обновляется везде; аватар загружается с круглой обрезкой; список по умолчанию меняется и используется при добавлении с главной.
- [ ] Плашка «Нет интернета» и тост ошибки сохранения работают; данные формы при ошибке не теряются.
- [ ] Подсказка установки показывается один раз в Safari на iPhone и доступна из профиля.
- [ ] Новый значок на экране «Домой» iPhone и в Dock Mac.
- [ ] RLS проверены; сборка, линтер чистые; ошибок в консоли нет; 390 px без горизонтальной прокрутки.

## Как проверить (для владельца)
1. Удалите пару желаний и один список. Профиль → «Корзина»: там эти желания с подписью «из «…»» и «удалится через 30 дн.».
2. «Восстановить» у желания из живого списка — оно вернулось в список. У желания из удалённого списка — появится выбор списка, выберите и восстановите.
3. «Очистить корзину» → подтвердите — корзина пуста.
4. Профиль: поменяйте имя на «Виталий» — оно поменялось в шапке (и в боковом меню на Mac). Загрузите своё фото и обрежьте по кругу.
5. Поменяйте список по умолчанию, затем добавьте желание с главной — оно попало в выбранный список.
6. Включите авиарежим — сверху «Нет интернета…». Попробуйте сохранить — тост об ошибке, введённое не пропало. Выключите авиарежим — плашка исчезла.
7. Удалите ME:WISH с экрана «Домой» и добавьте заново через Safari: значок — чёрный квадрат с лаймовым сердцем, подпись «ME:WISH».
