# 003-b — ТЗ для Claude Code: списки

**Этап:** 1 (второе из шести ТЗ, D-098)  **Связано:** SPEC §2.1–2.2, §2.5, §3.1, §3.3, §3.4a; DOMAIN §3 (List), §4; DECISIONS D-048, D-074, D-075, D-076, D-079, D-081, D-082, D-089, D-090, D-092, D-093, D-095, D-100; бриф `docs/design-briefs/003-personal-wishlist.md`
**Дизайн:** утверждён (D-097), выгрузка `docs/design/stage1/` (как читать — `README.md` там же).

## Контекст
003-a готово и проверено владельцем: дизайн-система, раскладка, схема БД с RLS, вход через Google, главная «первый вход» (отчёт `docs/reports/003-a-foundation-google-login.md`, заметки `docs/tech/stage1-foundation.md`). Сейчас у пользователя есть один список «Мои желания», а кнопки «+ Новый список» и обложки списков неактивны.

Это ТЗ — всё про **списки**: создать, открыть, отредактировать, удалить. Желаний пока нет (их добавление — 003-c), поэтому экран списка показываем в пустом состоянии.

## Что сделать

### 1. Создание списка
1. **«+ Новый список» работает везде:** в разделе «Мои списки» на главной (телефон) и в боковом меню (компьютер).
2. **Форма «Новый список»** — телефон `Mobile-NewList` (шторка снизу на всю высоту), компьютер `Desktop-NewList` (окно по центру). Поля:
   - **Название \*** — обязательно, красная звёздочка; рядом квадрат с выбранной иконкой на выбранном цвете, выровнен по высоте поля (D-089);
   - **Описание** — необязательно;
   - **Дата события** — необязательно, выбор в календаре (п. 3);
   - **Иконка** — сетка из 30 иконок (D-075);
   - **Цвет** — 8 цветов;
   - **Обложка** — два варианта в ряд: «Коллаж · 4 последних желания» (выбран по умолчанию) и «Иконка» (D-095).
3. **Календарь** — компонент `DatePicker` (`Mobile-NewList-Date`, `Desktop-NewList-Date`, D-090): тёмное всплывающее окно, дни недели с понедельника, сетка месяца, переход по месяцам, сегодняшний день лаймом, выбранный обведён, внизу «Убрать дату». Дата в поле — «14 марта 2027».
4. **Проверки:**
   - нажали «Создать список» с пустым названием — поле подсвечено, подсказка под ним (как ошибка поля в `Spec-Components`);
   - закрытие формы с введёнными данными — диалог «Не сохранять список?» с кнопками «Не сохранять» / «Продолжить» (по аналогии с D-081). Пустая форма закрывается без вопросов.
5. **После создания** список появляется на главной и в боковом меню, и сразу открывается его экран.

### 2. Экран списка
6. **Открытие:** нажатие на обложку на главной или на список в боковом меню открывает экран списка. У списка свой адрес (например, `/l/<id>`), его можно открыть напрямую и обновить страницу. Чужой или несуществующий список — «Страница не найдена».
7. **Раскладка** — телефон `Mobile-List`, компьютер `Desktop-List`:
   - шапка: назад (телефон), иконка списка, название, кнопка «•••»;
   - описание (если есть);
   - сводка одной строкой: «Активные N · сумма | Исполнено N · сумма» — по этому списку;
   - чипы «По приоритету» и «Исполненные».

   На компьютере открытый список подсвечен лаймом в боковом меню, «Главная» не подсвечена.
8. **Без описания** шапка компактнее (`Mobile-List-Compact`). Если нет даты, метки даты нет.
9. **Пустой список** — `Mobile-List-Empty` / `Desktop-List-Empty`: «Здесь пока пусто», пояснение, кнопка «Добавить первое желание». Кнопка и плавающая «+» пока неактивны, они оживут в 003-c. Чипы сортировки и «Исполненные» видны, но их работа — 003-d.
10. **Загрузка** — скелетоны `Mobile-List-Loading` / `Desktop-List-Loading`.

### 3. Меню «•••», настройки и удаление
11. **Меню «•••» списка** — `Mobile-List-Menu`, `Desktop-List-Menu` — всплывающее меню под кнопкой «•••» справа вверху, на обоих устройствах (как на макете). Пункты: «Редактировать», «Удалить» (красным). «Поделиться» нет (D-079).
12. **«Редактировать»** открывает ту же форму, что при создании, с заполненными полями: заголовок «Настройки списка», кнопка «Сохранить», внизу «Удалить список» (`Mobile-ListSettings`, `Desktop-ListSettings`). Закрытие с несохранёнными изменениями — «Не сохранять изменения?».
13. **«Удалить» и «Удалить список»** открывают диалог `Mobile-List-DeleteConfirm`: «Удалить список и N желаний? Желания попадут в корзину, их можно восстановить 30 дней». Для пустого списка — «Удалить список?» без строки про желания. После подтверждения — переход на главную и тост «Список удалён».
14. **Желания при удалении списка не стираются**, а уходят в корзину на 30 дней (D-082).
    - Сейчас удаление списка в базе каскадом стирает его `list_items` — это нужно поменять.
    - Как именно хранить желания удалённого списка, реши сам. Например, мягкое удаление списка (`lists.deleted_at`) и `list_items.deleted_at` у его желаний; удалённый список нигде не показывается.
    - Нужно, чтобы в 003-e корзина могла показать эти желания и восстановить их в другой список (с выбором списка, предвыбран список по умолчанию).
    - Сам удалённый список восстанавливать не нужно.
    - Записать решение в `docs/tech/`.
15. **Последний список удалить нельзя** (D-082): пункты «Удалить» и «Удалить список» серые, с пояснением «Нельзя удалить единственный список» (`Mobile-List-Menu-Last`). Защиту продублируй в базе.
16. **Удалили список по умолчанию** — по умолчанию становится первый из оставшихся (в базе, не только в интерфейсе).

### 4. Главная и боковое меню
17. **Обложки на главной кликабельные,** открывают список. Метка даты в углу обложки (`Cover`) — если у списка есть дата.
18. **Коллаж из фото** (D-089, D-095): сделай компонент обложки для 1, 2, 3 и 4 фото по `Cover.dc.html` / `Spec-Cards`. Реальных фото пока нет — проверь на подставных данных. При `cover_mode = icon` или без фото — обложка с иконкой.
19. **Боковое меню:**
    - пункты списков кликабельные;
    - активный пункт лаймовый, при наведении серая подсветка;
    - при многих списках внизу прокручиваемой части лёгкое затухание (`Desktop-Home-ManyLists`, отложено в 003-a).
20. **Порядок списков** на главной и в меню — по дате создания, новые снизу. Ручного порядка нет.
21. **Компоненты, которые понадобятся впервые:** поле ввода (обычное, с ошибкой, со звёздочкой), шторка (телефон) и окно (компьютер), всплывающее меню, диалог подтверждения (`Dialog`), тост (`Toast`; 4 секунды обычный, 6 секунд с действием — D-096). Делай по `Spec-Components` и `Spec-Feedback`, они пригодятся дальше.

## Что НЕ делать
- Добавление желаний, фото, кнопку «+» и «Добавить первое желание» — 003-c (остаются неактивными).
- Карточки желаний в списке, работу сортировки и «Исполненных» — 003-d.
- Экран корзины и восстановление — 003-e (здесь только правильно хранить удалённое).
- Видимость, «Поделиться», участников и приглашения — этапы 2 и 4.
- Ручную сортировку списков.

## Изменения в базе данных
- Удаление списка без потери желаний (мягкое удаление или другой способ — на твоё усмотрение, с RLS).
- Запрет удалить последний список пользователя.
- Перенос `default_list_id` на оставшийся список при удалении списка по умолчанию.
- Удалённые списки не попадают в `list_overview`, сводку и боковое меню.
- Перепроверить RLS на двух пользователях: чужой список нельзя открыть, изменить, удалить; удалённый список не виден.

## Критерии приёмки
- [ ] Можно создать список со всеми полями (название, описание, дата, иконка, цвет, обложка) на телефоне и компьютере; он появляется на главной и в меню и открывается.
- [ ] Экран списка по макетам: с описанием и без, пустой, загрузка; на компьютере список подсвечен в меню.
- [ ] Календарь по макету, «Убрать дату» работает.
- [ ] Редактирование сохраняет изменения; «Не сохранять…» срабатывает только при изменённых данных.
- [ ] Удаление: подтверждение с числом желаний, тост, переход на главную. Единственный список удалить нельзя. При удалении списка по умолчанию он переходит на другой список.
- [ ] Желания удалённого списка остаются в базе с отметкой удаления (проверить в базе на тестовых данных).
- [ ] Компонент коллажа выглядит законченно при 1–4 фото (на подставных данных).
- [ ] RLS проверены на двух пользователях, результат в отчёте.
- [ ] 390 px без горизонтальной прокрутки и переносов там, где на макете одна строка; ошибок в консоли нет; сборка и линтер чистые.

## Как проверить (для владельца)
1. На iPhone на главной нажмите «+ Новый список». Откроется шторка: впишите «День рождения», выберите дату в календаре, иконку торта и розовый цвет, нажмите «Создать список». Откроется пустой список «День рождения» с иконкой и надписью «Здесь пока пусто».
2. Назад — на главной две обложки, у «Дня рождения» метка даты.
3. Откройте список → «•••» → «Редактировать» → поменяйте название → «Сохранить». Название обновилось на главной.
4. «•••» → «Удалить» → «Удалить список?» → подтвердить. Вы на главной, тост «Список удалён».
5. Откройте «Мои желания» → «•••»: «Удалить» серый, «Нельзя удалить единственный список».
6. На Mac: в боковом меню «+ Новый список» открывает окно по центру; созданный список появляется в меню и подсвечивается лаймом, когда открыт.
