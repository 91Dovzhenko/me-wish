# Цикл работы

## Участники

| Кто | Где | Роль |
|---|---|---|
| Владелец | везде | решает, принимает работу визуально, переносит ТЗ и отчёты между Claude и Claude Code, пушит через GitHub Desktop |
| Claude (Projects) | проект me:wish в Claude + локальная папка | думает: интервью, требования, дизайн в Artifacts, ТЗ, разбор отчётов, ведение документации |
| Claude Code | та же локальная папка | делает: код, миграции Supabase, коммиты, отчёты |
| GitHub | репозиторий `me-wish` | код онлайн, деплой на GitHub Pages |

Все работают с **одной папкой** `me-wish` на Mac.

## Цепочка одной фичи

```
0 Сверка ─▶ 1 Интервью ─▶ 2 ТЗ на дизайн ─▶ 3 Дизайн (Artifacts) ─▶ 4 ТЗ для Claude Code ─▶ 5 Реализация ─▶ 6 Разбор отчёта
                                                                              ▲                                   │
                                                                              └──────────── доработать ───────────┘
```

| Шаг | Кто | Результат |
|---|---|---|
| 0 Сверка | Claude | что известно / чего не хватает |
| 1 Интервью | Claude + владелец | `interviews/NNN-*.md`, обновлённые SPEC / DECISIONS |
| 2 ТЗ на дизайн | Claude | `design-briefs/NNN-*.md` |
| 3 Дизайн | Claude | артефакт Design, ссылка в брифе и `DESIGN.md` |
| 4 ТЗ для Claude Code | Claude | `tasks/NNN-*.md` |
| 5 Реализация | Claude Code | код, коммит, `reports/NNN-*.md` |
| 6 Разбор | Claude | вердикт, следующее ТЗ или приёмка, обновлённые JOURNAL / BACKLOG / ROADMAP |

**Когда можно сокращать:** баг, правка текста, мелкое визуальное исправление — сразу шаг 4. Чисто техническая задача без интерфейса (например, исследование парсинга) — шаги 0 → 4 → 5 → 6.

## Нумерация

`NNN` — порядковый номер фичи, общий для всей цепочки: `001-setup`, `002-parsing-research`, `003-core-lists`… Несколько ТЗ внутри фичи — `003a`, `003b`. Отчёт называется так же, как ТЗ.

## Передача между Claude и Claude Code

- ТЗ лежит в `docs/tasks/`. Владелец пишет в Claude Code: «Выполни ТЗ docs/tasks/003a-core-lists.md».
- Claude Code пишет отчёт в `docs/reports/003a-core-lists.md`.
- Владелец пишет в проекте Claude: «Разбери отчёт 003a», а при необходимости прикладывает скриншоты.
